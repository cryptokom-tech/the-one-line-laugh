## The line

> I asked my smart speaker for relaxing music, and it started reading my search history aloud.

One line, 92 characters. A light, funny take on everyday life: the smart speaker meant to soothe instead exposes the one thing nobody wants read out loud, and the twist lands on the last word.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```
